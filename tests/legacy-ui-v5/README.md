# Historical browser fixtures for the 0.5 interface

These fixtures describe the retired photograph galleries, text-answer buttons,
explicit completion buttons, and Phaser parking UI. The touch refactor replaces
those contracts. They are retained here as review references and are outside the
active Playwright test directory, `tests/e2e`.

The current suite verifies all 26 activity entries and actual object gestures,
invalid drops, inertia, image-only matching, frame assembly, washing coverage,
road traversal, resize preservation, session retries, concurrent writes,
automatic artwork saving, favorites, stories, backup recovery, and entry failure.
Storage, audio, backup, and release unit tests remain active.
