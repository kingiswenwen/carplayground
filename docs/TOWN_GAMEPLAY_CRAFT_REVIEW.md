# 玩法车辆与物件精细化 · 0.18.0

这次修复的是小镇页面与实际玩法之间的美术落差：原玩法对所有GPU强制简化车辆材质，部分道具由无细节的盒体、圆锥或薄挤出图形组成，手机画面中的帽子、水具和背包过小。

## 实际变化

- 33个主要物件图标采用同一套微缩玩具美术，DOM与平面Canvas共用；来源、裁切范围、透明度与文件SHA-256登记在`content/play-icons-production.json`。图像失败时回到本地矢量，入口和玩法继续可用。颜色与方向等教学符号保留明确的语义绘制。
- 立体背包、雨衣、帽子、水瓶、喷头、安全带、扳手、轮胎、书、人物、座椅和手推车增加对应结构；网格按原物件尺寸统一缩放。修正洗车喷头被画成饮水杯、搬运工具被画成包裹的问题。
- 普通已识别GPU保留车辆Standard材质、有限环境反射和阴影；软件GPU或身份未知时使用单次Phong着色、静态接触阴影和约720像素的长边预算。手机画布不再统一放大0.65倍的低分辨率画面。可选环境初始化失败时回到较轻的材质路径。
- 手机出行、打包、协作和顺序活动按物体与有效目标取景；强化目标边线。3D/2D切换继续使用同一会话，模式有对应图形和状态标记。后续道路阶段的箭头与画纸控件使用明确的实物图形，不再是空几何或占位球；切换视图保留纸色。
- 26张活动封面重新取自实际规则引擎。封面可使用平衡着色路径在无头软件GL中捕获；该记录与真实硬件验收分开。

## 教学与既有功能保留

与开工核对的主线`93e9195`比较，`content/r3.json`的activities、stories、cars、speech、scenes、vocabulary、phrases结构内容相同，`content/vehicle-models.json`未修改。保留26项活动、8个领域、3条四幕故事、106款登记车型；没有替换车型为通用车身。

没有改动数量、颜色、桥长、道路方向、部件命中规则、活动判定或备份结构。阴影、物件细节和取景属于表现层；装配仍使用车型来源部件，颜色受限车型仍走原来的正确颜色平面玩法。SVG降级、键盘、点选放置、洗车轮流、作品保存和故事续幕继续保留。
