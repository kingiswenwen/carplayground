# 汽车小镇插画关卡制作记录

宋宋在《我用 ChatGPT 做了一款微信小游戏》中先用简陋原型试一关，操作顺畅后才出美术。她分别试过整图后抠图和物件各自出图，最终选了先生成一张带有玩法逻辑的整图，再拆出互动物件。后续以实际操作录屏与截图定位问题，反复改同一个位置。本项目采用这套制作顺序，场景、物件和玩法沿用汽车小镇的原创题材。参考依据为长文正文和公开附图。 [原帖](https://x.com/songsong/status/2123013876249944333)

## 每关的制作顺序

1. 把一轮游戏做成可操作灰盒。记录画面上看得到的线索、物件位置、可用动作、错误结果和继续的方式。实际操作直至看见预期结果，再定画面的构图。
2. 出一张含有实际物件、落点和环境关系的完整原画，检查物件是否一眼可辨、位置是否在操作范围内，以及留给运行时小车的距离是否够。
3. 用同一整图编辑出干净的背景，拆出会移动或改变状态的透明图层。用实际桥石、停止线、托盘等构图锚点对齐规则坐标。背景、贴纸和关键道具分层保存并登记尺寸与哈希。
4. 接回原活动入口。用同一组选车、输入和规则，重走灰盒路径。检查触碰是否发生在看见的物件上，查看拖走后的空位置、错误反馈、结果和保存后的内容。复用图层方法时，为每关单独定位置和状态。

## 接入情况

| 活动 | 灰盒因果 | 全图与分层 |
| --- | --- | --- |
| T02 给小车搭桥 | 短板搭不到对岸；第二段的长板收在木料棚。孩子可点开棚，拖出板，重新试车。 | 木料棚、草席、桥石和路在一张原画里。独立桥板及棚门覆盖在干净背景上，桥石随河宽对齐。 |
| E03 出发和停止 | 红灯在停止线前拦车，行人走完后换绿灯，再由孩子推车。 | 停止线和斑马线留在底图里。行人、信号灯单独切出，灯色跟随规则切换。 |
| A01 车展海报 | 可取用同一款贴纸多次、点放或拖放、重新移动、撤回和主动保存。 | 同一工作台原画包含画纸、颜料盘和托盘。叶子、太阳、星星三张透明图层可贴到画纸上，并沿用到保存和 PNG 导出。旧作品沿用原有图案。 |
| E01 发现颜色 | 看灯选车。合适的车登台后，展台和提示换位置。 | 从同一展厅原画拆出展台与灯，沿木轨换位置。候场车与已登台车辆有不同的停放位置。 |
| E02 汽车的身体 | 转车轮，开关门和灯，观察各部件的作用。 | 选定的真实车型绘在展台上。开门时显示座位示意，灯亮照到展厅地面。 |
| C01 我喜欢这辆车 | 布置和移动展台道具，换背景，查看观众位置并保存。 | 从展厅原画拆出灯、站牌和树。布置保存采用同一组道具图层。 |
| M01 小车回家 | 实体挡板会挡车，孩子可以倒回换空位。 | 停车院中的车位与红白挡板各自分层，位置跟随当前关卡。 |
| M02 还缺几个车位 | 先停现有两辆，再安装车位板给第三辆车。 | 木料是独立道具，安装后落点变成有实体边缘的车位，另一块空地仍可见。 |
| M03 车位够不够 | 长车后到，小车可以挪出被占的长位。 | 停车院使用较长的停车板和可比较的标尺。 |
| M04 红蓝车队 | 接完重复顺序，观察两队依次出发。 | 游行街全景保留两条路线，裁出的检查门和待上场车分层绘制。 |
| L03 整理车库 | 同样的车先按颜色停车，再按长短停车。 | 停车板和挂牌可独立换位置与条件。 |
| T01 零件帮什么忙 | 车轮解决移动问题，乘客到门口，车灯照亮隧道。 | 从完整工坊拆出乘客和指示旗，保留隧道位置作为车灯反馈的背景。 |
| T03 把路连起来 | 路块转动改变开口，试车只沿接通的路线行驶。 | 从道路工作台原画拆出直道与弯道，按真实出口转动。 |
| T04 装好自己的跑车 | 缺轮试车会晃，补齐后驶过试车线。 | 试车台与轨道在原画里，试车旗独立，车身与轮子仍来自所选原车型。 |
| H02 谁能帮忙 | 扳手检查车轮、海绵擦泥、小推车搬走箱子。 | 同一服务院拆出工具和伙伴角色，使用后在实际作业位置移动。 |
| H03 泡泡洗车屋 | 水冲掉浮尘，海绵擦泥成泡沫，再用水冲走。 | 喷头、海绵从洗车台整图独立切出，所选工具和表面污渍分别显示。 |
| L02 请你帮帮我 | 碰到挡板后请求伙伴，伙伴挪开挡板，孩子再推车。 | 伙伴和红白挡板各是可移动图层，沿停车道显示实际位置变化。 |
| S01 什么会滚 | 先猜测，再用同一挡板放开球和方块，比较停点。 | 球、方块和挡板由同一实验台原画拆出，球随移动转动。 |
| S02 车灯和影子 | 拖灯改变影子方向和长短，保留一次旧影子。 | 整图中的灯可拖走，树和地面标线作为固定比较参照。 |
| S03 雨天出发 | 在同样的雨滴下试物件，对比纸卡干湿。 | 云和四种物件独立切出；纸卡显示雨滴与水痕。 |
| P01 推一推跑车 | 交换路面，用相同的推力做两次比较。 | 从同一科学台裁出光滑与粗糙的可交换路面，保留两轮停点。 |
| L01 出发准备 | 装水、扣上安全带后，孩子才能把车开出门。 | 原画保留背包、座位和门柱，三种随身物件及挡杆单独切出。 |
| H01 去看看 | 驶向目的地，再操作物件看发现。 | 从地图拆出三站的图章，抵达后放大当地环境，并保留访问记录。 |
| C02 先做什么 | 按孩子排的顺序演出，先后条件没满足时在画面上停下。 | 从完整戏台拆出道具卡；演出显示正在实践的一步，可换出游与洗车。 |
| C03 接着讲下去 | 开门会改变第二幕里的物件，可移动角色、撤回并复播。 | 第一幕的门、树、旅人和星星分层。第二幕有单独的黄昏花园原画。 |

26 个原入口默认展示插画场景。`view=3d` 与现场切换按钮仍可进入原有立体玩法，两个视角共用局内状态。活动规则采用同一辆登记车型与同一组操作坐标。插画资源加载失败时使用可操作的绘图场景回退。

工作区的 `scratch/carplayground-scene-workflow` 保存 26 项 390 × 844 的实玩截图。T02 另有灰盒、完整原画、分层和实玩对照。手机触控采用 Chromium 原生触摸事件，键盘和立体兼容通过项目浏览器回归测试。本轮工作在现有 `dev` 上，交付为本地版本。
