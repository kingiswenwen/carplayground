# 汽车小镇玩法重做方案

把小镇的 26 项活动重新设计成孩子能看懂、能动手、能验证结果的场景。保留六个地点与汽车主题。孩子带自己的车解决眼前的问题，动作造成可见后果。自由创作可以继续玩、保存、重来，由孩子决定作品何时完成。

## 从推文借什么

宋宋的长文《我用 ChatGPT 做了一款微信小游戏》记录了《谜题必须解开》的制作过程。文章第一关的例子是从一幅画里找齐人物。第二个原型截图「新房迎亲」显示场景、待完成事项和动态进度。能从截图与正文确认的是，物件嵌在有具体任务的场景里，玩家靠观察和操作推进任务。试玩入口是封面上的微信小程序码，本次依据文章和截图，未在微信内实机通关。 [原帖](https://x.com/songsong/status/2123013876249944333)

值得直接采用的是三步制作顺序。先用简单形状做出可玩的场景，验证孩子是否知道去哪看、拿什么、动作后发生了什么。再定完整原画的视角和物件位置，把可交互物件拆成透明图层。最后替换原画、补声音和效果，分别检查玩法有没有变难、哪里遮挡或拖不动。也可以复用同一套交互做不同条件的关卡。比如河变宽要换桥板，红灯亮要停下来等过街，两种变化各有实际后果。

场景里要有可用的线索，比如桥两头的支点、车位挡板、湿掉的纸卡。工具盒、抽屉和门只在打开后能看到或取出有用的东西。孩子可以看场景、听一次短口令，或者点操作示意。线索能看出来之后再加入探索，允许几条合理路线、工具或摆放结果。

## 现状与依据

用项目实际代码的 390 × 844 平面玩法截取 26 张入场画面。复核规则代码和现有交互用例。全量进入场景成功，截图采集没有页面错误。试玩观察是浏览器层面的证据，孩子是否愿意重玩仍要做陪玩观察。记录文件和三张缩略图板存于工作区的 `scratch/carplayground-review`。

1. 展厅的 E02 和工坊的 T01 入场画面几乎相同，两站也用同一个部件触碰模式。孩子点到热点，就能看到零件变化，缺少把零件功能用到情境里的机会。
2. 停车广场的 M01、M02、M03、L03 主要操作是把车放入方框。M02 的确要求补车位，但增加方框后马上回到同一动作。容易相互混淆，也难练出看空位、补容量和预留车位这三种不同判断。
3. T02 和 T03 已经有放板或接路后车能实际通过的反馈。这比只涨进度更贴合任务。平面界面里支点比较抽象，T02 只有两块板，错的一块试完就知道答案，进阶需要新的河宽或支撑条件。
4. C01 与 C03 使用同一组太阳、树、星星，两个物件放进场景就达到参与条件。A01 和 A02 开场画面也高度相似，但规则一项是摆图，一项是让车留下轮印。玩法入口和操作对象应提前呈现这种差异，自由表达不以摆放次数判定好坏。
5. H02 是有固定答案的三组工具配对。L02 通过拖招手卡求助，孩子没机会尝试自己暂时做不到的事或看到伙伴怎样帮忙。道具占手机屏幕比例较小，拖拽目标暴露成方框。要用更大的可点区、明显的选中状态和真实情境中的落点。
6. S01 和 P01 已具备比较对象与滑行动作，S02 的影子也随光源变化。下一版应把预测、改变一个条件、保留结果再比较做成孩子看得懂的操作，减少小图标或文字替物件解释结果。

截图中的目标大小和可见线索用于判断设计风险。触控延迟、色觉差异、听音理解、手部动作和无成人提示完成情况要在样关上另行验证。

## 26 项怎么改

每项都列出孩子遇到的具体问题、要做的动作、可见结果。ID 用于把这一版和旧路径、故事链接及历史记录对上。

| 地点与活动 | 新的场景与操作 | 孩子能看到的结果 |
| --- | --- | --- |
| 展厅 E01 发现颜色 | 展台只缺接下来要登场的车。看台灯颜色、听车名口令，从两辆起步，点车再点展台或把车开进去。颜色是练习内容，听音提示可直接重听。 | 对应车停上台才亮灯。进阶轮换目标颜色和车位，颜色不会固定在某个位置。 |
| 展厅 E02 汽车的身体 | 进展厅前做三项表演。手转轮、打开门、点亮车灯，留出一段可随意检查的时间。 | 轮子按手势转、门打开能看见座位、灯亮后照到路面。比较不同部件各自怎样动。 |
| 展厅 E03 出发和停止 | 小车要过有行人的路口。看灯和停止线，用连续按住或拖动车辆控制行进。 | 红灯在停止线前等，行人走完后再出发。过早推会在停止线前停住，可以马上调整。 |
| 展厅 C01 我喜欢这辆车 | 布置自己的展位。选好爱车，再摆灯、站牌和背景；能移动、移除或换景。 | 展位照着孩子的布置变化，可以切到观众角度，然后自行保存。 |
| 停车 M01 小车回家 | 找到没有车也没有路障的车位，沿引导车道把车开进去。先用一辆车，熟练后让第二辆开进来。 | 挡板实体挡住车，能倒回再选。停实后车位标记变为已用，形成一辆车占一个位的对应。 |
| 停车 M02 还缺几个车位 | 同时来几辆车。先给现有车位停车，再用一块或多块车位单元补出空间。 | 还有几辆在等一眼可见，多加的位也空着。进阶改变来车数和可用空地。 |
| 停车 M03 车位够不够 | 车队回家时要给晚到的校车留一个长位，普通车可以停到多个位置。 | 校车入场验证腾出来的空间够不够，停错可挪车；孩子能拿两个安排比较。 |
| 停车 M04 红蓝车队 | 两节已经排好的游行车队经过广场，孩子从候车区接下两辆，进阶可以看见两种不同的重复节奏。 | 小队开过检查线时按自己的规律亮灯；进阶用不同起点与重复单元，避免背位置。 |
| 停车 L03 整理车库 | 先看当天的车库挂牌，可按颜色整理，下一轮换成车身长短。 | 同一辆车在不同规则下会去不同车库。门口有重复的色块、形状和必要语音，能回头更正。 |
| 工坊 T01 零件帮什么忙 | 给现场的小车解决问题。暗路口要选车灯，乘客要上车则开车门，小车要移动就让轮子转。 | 启用的部件直接改变场景，孩子可以重新观察部件和任务的对应。 |
| 工坊 T02 给小车搭桥 | 从河岸支点判断跨度，把候选桥板拖或点放上去，再推小车试走。进阶切到更宽的河段。 | 短板只够一岸，车停在安全线。合适的板搭到两岸，车能过去。看得见为什么成或没成。 |
| 工坊 T03 把路连起来 | 转动直路和弯道，把车从工坊引到指定地点。进阶给一个断路和两条可绕行的路线。 | 车只沿真正连通的出口走，在断点停住并指向断口。可比较两种路线。 |
| 工坊 T04 装好自己的跑车 | 装车身和练习部件，先左右放轮，再推出测试台。在练习车上支持调换或拆下重装。 | 缺轮车不能平稳滚动；都装好才沿短轨滚走。教学动画只用模型演示。 |
| 工坊 H02 谁能帮忙 | 观察需要检查的轮胎、要清洁的车身或待搬物品，从可见工具架拿工具交给伙伴。 | 伙伴实际检查、清洁或搬运。工具不合适时由物件状态提示哪里还没处理。 |
| 洗车 H03 泡泡洗车屋 | 给泥车选择冲水、刷洗或冲走泡沫。进阶车有两种污渍，可比较喷水和刷洗的效果。 | 污渍与泡沫随操作局部变少，干净部位有变化；完成后孩子可以请下一辆来。 |
| 洗车 L02 请你帮帮我 | 小车卡在洗车屋门口。孩子先试推，再选择招手、呼叫伙伴或递出求助图卡。 | 伙伴过来与孩子一起挪开轻挡板。记参与和所用方式，允许孩子尝试多种求助。 |
| 公园 S01 什么会滚 | 在同一坡道顶放球和方块，先选一个预计会滚更远的，再用同一个挡板放开两件物体。 | 留下停点，球滚、方块停或滑；换一次表面后还能对比。猜错也能完整看实验。 |
| 公园 S02 车灯和影子 | 拉动灯照小车，试着让影子落进树旁或停车线旁；还能换灯的远近。 | 保留上一次淡色影子与当前影子，看得出方向和长度怎样变。 |
| 公园 S03 雨天出发 | 看到窗外下雨，为乘客选雨具。在同样雨滴下试雨伞、雨衣和其他物品。 | 纸卡湿或干，效果和用法相关。允许合理的防雨组合，选错可以重新试。 |
| 公园 P01 推一推跑车 | 同一次推力传给相同两车，观察两种路面的停点。交换路面，再用类似的力推一次。 | 两次停点指示物保留。孩子能观察距离随路面变化，并区分推力和路面的影响。 |
| 公园 L01 出发准备 | 看天气和目的地拿水或遮阳物品，再在模拟座位上扣安全带。让孩子自己开出门。 | 车在出口前给出可行动反馈，扣好后出发。用视觉表现安全带位置和状态。 |
| 公园 H01 去看看 | 驾车选一个目的地。到达后打开一扇能操作的门或翻一件展品，再决定去哪。 | 各目的地展示独立操作与不同发现，回地图仍能看到去过哪里。 |
| 画室 C02 先做什么 | 用实物排出发顺序，再点播放，按孩子的顺序演一遍。可换用「洗车前」或「出游前」场景。 | 必须先发生的事会影响后续，如车门未关车不能起步。无因果依赖的步骤允许换序。 |
| 画室 C03 接着讲下去 | 用贴纸在两幕之间讲小车故事。移动角色或开门会改变下一幕可用物件，支持撤回。 | 复播看到自己摆的动作顺序，能重新编排。记录参与，孩子可以讲给家人听。 |
| 画室 A01 车展海报 | 给爱车布置海报。点放或拖贴纸，移动、撤回与替换；提供原模衍生车图。 | 最终效果预览、保存到车库、导出图片。作品内容由孩子决定。 |
| 画室 A02 轮印花纹 | 换轮纹和颜料，推车横过画纸，下一遍叠印或换路径。 | 路径和轮纹直接生成图案，能观察连续、重复和交叠，支持撤回和保存。 |

## 正式活动改造进度

| 活动 | 已接入的操作 | 保留的兼容性 |
| --- | --- | --- |
| T02 给小车搭桥 | 两段不同跨度，短板会留在河上，试走后车停在岸边并点亮另一端支点。通过第一段可以去更宽的一段，完成两段才记下发现。 | 原小镇、故事和深链接，平面/立体共用桥板与进度，方括号选择及回车试走。 |
| E03 出发和停止 | 推车到停止线后，红灯会挡车并让行人走斑马线。行人过完换绿灯，下一次继续推车才算完成。信号灯只读出当前状态。 | 原活动入口、go / stop 音频、分步演示、拖动和键盘。 |
| A01 车展海报 | 选纸色、颜色和贴纸，点放或拖放。每个贴纸可重新移动，可重复从工具架取用，也能撤回。保存才记录参与，可另存 PNG。 | 旧作品及导出格式、车库、平面和立体共用同一画纸和作品。 |

| M01 小车回家 | 额外的车位有实体挡板，车会在挡板前停住，可倒回并换空位。 | 留下一辆和两辆两个阶段，可拖可点放。 |
| M02 还缺几个车位 | 先看队列和现有车位，选择两片空地中的一片加装唯一的车位板，才可以停进车。 | 两种放置结果都能完成，车位选择与车数不绑定。 |
| M03 车位够不够 | 两辆小车停好后长车到场，只能停长位；普通车占了长位，可以挪到短位后再停长车。 | 沿用真实车型与原活动入口。横竖屏切换保留已停车辆。 |
| M04 红蓝车队 | 先接红蓝交替队伍，再接蓝蓝红的队伍。每接完一队都能看到车队依次向前。 | 保留两种颜色的准确呈现；两队都通过才记录。 |
| L03 整理车库 | 同一组车先按颜色放置，再切换到按长短放置。原来能停的位置可能需要换。 | 使用同一批真实车图，长短用车身比例和车库横尺呈现。 |

| T01 零件帮什么忙 | 先让车轮转动，再帮乘客上车，最后用车灯照亮出口。碰错部件不会推进当前任务。 | 继续用所选车型的真实部件触碰区，一步和三步两种阶段，键盘同样按情境逐步操作。 |
| T03 把路连起来 | 接路之后由孩子发车试走；开口错位时车停在断口。第三段中间封路，两侧可分别接通。 | 直路和弯路只旋转原形状。平面和立体共用路线判断，可重试及体验另一侧。 |
| T04 装好自己的跑车 | 缺轮时试车会晃，轮子可以取下、调换；装齐且试车稳稳滚过去才记录完成。 | 保留多车型和点放、拖放，试车可点击或键盘触发。 |
| H02 谁能帮忙 | 根据看得见的轮胎、泥点和箱子选工具，观察扳手检查、海绵擦泥和箱子随推车移动。 | 工具分类仍按实际用途，三件事完成才记录。 |

| H03 泡泡洗车屋 | 水冲掉浮尘，海绵把黏泥擦成泡沫，再用水冲走。下一辆车混合了两种污渍。 | 换视角、转屏和立体回退继续处理同一组脏点。 |
| L02 请你帮帮我 | 推车碰到挡板后可招手、呼喊或递求助卡。伙伴挪开挡板后由孩子自己推车通过。 | 保留参与记录，并记下采用的求助方式。 |
| S01 什么会滚 | 孩子先猜，点同一个挡板同时放开球和方块。换坡面时保留前一轮停点。 | 任何预测都可以继续。键盘可猜、放挡板和换坡面。 |
| S02 车灯和影子 | 移灯改变影子的方向和长度，留着上一次影子做对比。 | 影子位置在平面、立体及转屏后按同一组记录恢复。 |
| S03 雨天出发 | 在同样的雨滴下试两种准备方式，纸卡会显出湿点；雨伞、雨衣或它们的组合能覆盖纸卡。 | 可放入不同物件做试验，可反复换一组并比较记录。 |
| P01 推一推跑车 | 一次手推启动两辆同款车，交换路面后，从同一起点用同样的力重试。 | 原拖车手势、倾斜选项和平面/立体共用结果。保留两轮停点。 |
| L01 出发准备 | 根据晴天公园场景带水、扣模拟安全带。没准备好时车停在门口，准备好后小车驶过出口。 | 保留故事入口。物品、扣带与开车是独立操作。 |
| H01 去看看 | 停到公园、图书馆或博物馆，到站再操作花丛、故事书或标本箱。 | 发现后记录参与，回地图还可去下一站，已去过的地点有标记。 |
| E01 发现颜色 | 对照灯光颜色把车送上台，只有对应车型登台才亮灯。后续车辆换到另一展台位置。 | 保留红蓝两色和红蓝白三色阶段、颜色正确的车型图、语音与键盘。 |
| E02 汽车的身体 | 展厅里用手转动车轮、开关门、点亮车灯；开门可看座位示意，灯光照到地面。 | 继续使用原车型部件区域。立体座位采用教学剖面，玩完可继续操作。 |
| C01 我喜欢这辆车 | 为选好的车布置灯、站牌、背景和树，道具可移动、移除或撤回。可看观众角度并自行保存。 | 沿用车库里的海报作品格式和原有选车入口。 |
| C02 先做什么 | 把实物放进任意顺序，播放看后果。出游和洗车有不同的准备条件，能重新交换再试。 | 仅先后依赖的步骤会阻挡后续，独立准备的顺序可交换。 |
| C03 接着讲下去 | 移动车或开门会改变第二幕出现的物件。可以撤回或复播自己编排的动作。 | 保留自由表达的参与记录。两幕场景可在平面、立体间切换。 |
| A02 轮印花纹 | 不同轮纹和颜色沿实际推车路径印在画纸上，可叠印、撤回上一趟并保存。 | 沿用旧轮印作品格式和本机车库。取消拖动不会提交本次轨迹。 |

## 样关与验收

先做 T02「给小车搭桥」、E03「出发和停止」、A01「车展海报」三关。分别检验解决问题、连续控制、自由创作。机制确认后推进实验和行程，再把其余活动逐一接到六个地点。优先用原始形状和当前合格的车辆验证操作节奏，再出美术。三关都应保留原 URL 的回退能力，切屏后保持同一局进度。现有记录继续可读，改变规则的活动上线时提升自己的内容版本，避免把新旧活动结果混作同一套。

T02 首轮的例子是有矮石支点的浅河。孩子看见对岸的目的地和一块明显偏短、一块合适的候选桥板。短板可以搁下，但对岸留空，小车停在近岸，局部提示只点亮对岸支点。正确放置后推动小车通过。第二轮改变跨度或加一段支撑，要求使用同样的比较方法。关卡判断来自板端是否有支撑以及车是否到达对岸，而不是放下过几次。拖放和点选放置都能用，键盘可选板、放置和试车。

本轮已做成独立的 T02 双河段玩法样关，文件为工作区 `scratch/carplayground-review/bridge-prototype.html`。用 390 × 844 的 Chromium 触摸模式检查了无桥拦截、短板停在近岸、原生触摸拖放、加宽后重新比较、键盘操作与重试，并截取了起点、短板与最终过河三个状态。样关用于验证玩法，正式 T02 已据此接回原入口。

手机验收从 390 × 844 开始，同时查窄屏、横屏和桌面；在手机上验证单手点选、手指移出对象范围、抬手、取消、重试和切屏；主要目标至少 44 CSS 像素并避免遮住目标。在音频关闭时仍能从场景看懂。自动化验证规则、误放回退、完成路径和本机记录，实际观摩则记录孩子有没有主动开始、遇错能否理解后果、学过一轮能否迁移到改过的第二轮，以及会不会自己选择重玩。保留开放活动的参与记录与闭合活动的任务结果两种含义。
